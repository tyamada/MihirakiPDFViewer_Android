MihirakiPDFViewer

Pembaca PDF modern yang dioptimalkan untuk tampilan dua halaman dan pembacaan R2L di Android

Dukungan Kebijakan Privasi Qiita GitHub

✨ Fitur Utama

📖 Tampilan Dua Halaman yang Mulus

Lihat dua halaman berdampingan. Sempurna untuk tata letak manga dan buku seni yang imersif.

🇯🇵 Dukungan R2L Asli

Dukungan penuh untuk urutan baca kanan-ke-kiri, termasuk slider terbalik dan gerakan geser yang intuitif.

🔄 Deteksi Otomatis

Secara otomatis mendeteksi tata letak halaman dan arah baca dari metadata PDF untuk pengalaman tanpa konfigurasi.

🔍 Pencarian Presisi

Pencarian teks cepat dengan penandaan hasil yang akurat (latar belakang kuning dan bingkai merah) pada dokumen.

🛡️ Privasi Utama

MihirakiPDFViewer dirancang dengan privasi sebagai intinya.

  • Semua pemrosesan PDF dilakukan secara lokal di perangkat Anda.
  • Dokumen Anda tidak pernah diunggah ke server eksternal mana pun.
  • Tidak ada izin internet yang tidak perlu yang diperlukan.

PDF diproses di perangkat Anda. Pengunduhan contoh, layanan cloud, pemeriksaan pembaruan, dan pembelian dukungan opsional menggunakan koneksi jaringan.
