## 実機テストスクリプト

- 端末識別子を必須指定。接続端末の先頭を自動選択しません。GradleにもANDROID_SERIALを引き継ぎます。
- 既定collectモードは実インストール版・モデル・Android版の収集のみ。アプリ起動、インストール、削除、データ・ログ消去、端末UI試験は行いません。
- Debug試験は明示指定。Playからインストールされたアプリは保護し、専用テスト端末で実施します。データ保持インストール失敗時に自動削除しません。
- クリーン試験は専用オプションと同じ端末識別子の再指定が必要。データ削除をガイドに明記。
- 必須工程の終了コード・起動・プロセス・JUnit件数／失敗／エラー／スキップを評価。JUnitの古い結果を削除し、タスクを再実行して新しい結果を取得します。空の結果・全件スキップ等を合格にしません。
- ソースの版番号を推測せず、端末から版番号を取得。動作確認一覧は自動上書きしません。情報収集成功／自動試験成功／手動未確認を分けます。
- 個人環境の固定パスを撤去。JAVA_HOME・ANDROID_HOME等の環境設定を利用。全端末の広範なログ収集をやめ、Debug時のアプリプロセスのログを保存します。共有前の確認も案内。
