MihirakiPDF

专为 Android 上的双页跨页和从右至左（R2L）阅读优化的现代 PDF 阅读器

隐私政策 GitHub

✨ 核心功能

📖 无缝跨页

左右并排查看双页。非常适合沉浸式阅读漫画和画集布局。

🇯🇵 原生 R2L 支持

完整支持从右至左的阅读顺序，包括反向进度条和直观的滑动手势。

🔄 自动检测

自动从 PDF 元数据中检测页面布局和阅读方向，实现零配置的优秀体验。

🔍 精准搜索

快速文本搜索，并在文档中提供准确的高亮显示（黄色背景与红色边框）。

📱 屏幕截图

🛡️ 隐私至上

MihirakiPDF 的设计核心即是保护隐私。

  • 所有 PDF 处理均在您的设备上本地进行。
  • 您的文档绝不会被上传到任何外部服务器。
  • 无需请求任何不必要的网络权限。

*注意：仅在您明确从 Google Drive 等云端存储服务中打开文件时才会使用网络连接。
