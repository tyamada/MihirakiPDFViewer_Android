PRIVACY-FOCUSED ANDROID PDF VIEWER

The ultimate two-page spread reader for manga and PDFs.

Designed for right-to-left documents and spreads. Enjoy smooth local rendering, outline tree navigation, and precise search highlights for PDFs stored on your device, even offline.

FEATURES

Built for comfortable reading

Read manga, magazines, and documents with complete right-to-left support and intelligent layout detection.

📖

Two-Page Spread

Seamlessly display two pages side-by-side with cover mode support.

🇯🇵

Right-to-Left (R2L)

Native support for Japanese and traditional reading directions.

📑

Outline Navigation

Jump instantly to any chapter or section using PDF bookmarks.

🔍

Fast Text Search

Search text with precision yellow background and red outline highlights.

🛡️

Local PDF Processing

Read PDFs stored on your device offline. Select files with Storage Access Framework.

📱

Adaptive Layout

Optimized for phones, tablets, foldables, and desktop window modes.

DIAGNOSTICS & LOGGING

On-Device Testing & App Logs

Run device diagnostic tests and inspect secure local app logs (AppLogger) stored safely for up to 24 hours. Never sends data externally automatically.

OPTIONAL SUPPORT

Support the Developer

All core reading features are completely free. Optional one-time supporter tips (Bronze, Silver, Gold, and Koyomi badges) unlock commemorative supporter badges in the app settings.

PDF processing takes place on your device. Sample downloads, cloud services, update checks and optional support purchases use network connections.

Sample PDFs start with the latest episode. Switch to Episode 1 first or latest first; your order is saved and also applies when filtering by language.
