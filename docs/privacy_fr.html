Politique de confidentialité

Le développeur de MihirakiPDF (« l'Application ») respecte votre vie privée. Cette politique décrit la manière dont nous traitons les informations.

1. Collecte et utilisation des informations

L'Application ne télécharge **pas** et ne collecte pas vos fichiers PDF. Tout le traitement des PDF est effectué localement sur votre appareil. L'Application utilise uniquement la connectivité Internet dans les scénarios limités suivants :

  • Lorsque vous ouvrez explicitement un fichier à partir de services de stockage cloud comme Google Drive.
  • Lorsque vous effectuez un achat via l'application (pourboires de soutien) via le système de facturation Google Play.

2. Autorisations

L'Application utilise le framework d'accès au stockage (Storage Access Framework - SAF) pour accéder uniquement aux fichiers spécifiques que vous sélectionnez. Nous ne demandons pas d'autorisations d'accès globales au stockage.

3. Sécurité des données

Étant donné que vos documents ne quittent jamais votre appareil, vos données restent sous votre contrôle.

4. Contact

Pour toute question concernant cette politique, veuillez nous contacter via le dépôt GitHub.
