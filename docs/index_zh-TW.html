MihirakiPDFViewer: 雙頁 PDF 閱讀器

針對 Android 跨頁與右至左閱讀優化的現代 PDF 閱讀器

支援 隱私權政策 Qiita GitHub

✨ 主要功能

📖 無縫跨頁

並排查看兩個頁面。非常適合沉浸式漫畫和畫冊配置。

🇯🇵 原生 R2L 支援

完整支援從右至左的閱讀順序，包括反向滑桿和直覺的滑動手勢。

🔄 自動偵測

從 PDF 中介資料自動偵測頁面配置和閱讀方向，實現零配置體驗。

🔍 精準搜尋

快速文字搜尋，並在文件上提供精確的命中標示（黃色背景和紅色邊框）。

📱 螢幕截圖

📚 範例 PDF

使用以下範例 PDF 檔案體驗本應用程式：

共51份PDF，涵蓋14種語言、17種語言及地區版本，每種3話。西班牙／拉丁美洲、巴西／葡萄牙、台灣／香港分開篩選。香港版採用標準書面中文，並非口語粵語版。下載時驗證大小與SHA-256，並保留舊PDF。

🛡️ 隱私優先

MihirakiPDFViewer 的設計核心即是保護隱私。

  • 所有 PDF 處理均在您的裝置上本地執行。
  • 您的文件絕不會上傳到任何外部伺服器。
  • 不需要任何不必要的網路權限。

PDF 在您的裝置上處理。下載範例、使用雲端服務、檢查更新和選用的支持購買會使用網路連線。
