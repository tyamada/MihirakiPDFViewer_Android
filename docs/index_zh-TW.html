隱私權政策 GitHub

✨ 主要功能

📖 無縫跨頁

並排查看兩個頁面。非常適合沉浸式漫畫和畫冊配置。

🇯🇵 原生 R2L 支援

完整支援從右至左的閱讀順序，包括反向滑桿和直覺的滑動手勢。

🔄 自動偵測

從 PDF 中介資料自動偵測頁面配置和閱讀方向，實現零配置體驗。

🔍 精準搜尋

快速文字搜尋，並在文件上提供精確的命中標示（黃色背景和紅色邊框）。

📱 螢幕截圖

🛡️ 隱私優先

MihirakiPDFViewer 的設計核心即是保護隱私。

  • 所有 PDF 處理均在您的裝置上本地執行。
  • 您的文件絕不會上傳到任何外部伺服器。
  • 不需要任何不必要的網路權限。

*注意：僅在明確從 Google Drive 等雲端儲存服務開啟檔案時才會使用網路連線。

💰 定價

免費且無廣告

本應用程式完全免費使用。無論是否購買，所有核心功能（如 PDF 查看、跨頁和搜尋）均無任何限制地提供。

*提供選用的應用程式內小費以支援開發者。支援者將在設定畫面中看到特別的紀念徽章。
