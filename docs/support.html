Frequently Asked Questions (FAQ) & Guide

1. How to open a PDF?

Tap the folder icon or open button in the toolbar to select a PDF file from your device storage or cloud storage using the system file picker.

2. How to navigate pages?

Swipe left/right across the screen, use the bottom page slider, or click the left and right edges of the PDF image (on desktop/mouse navigation mode, configurable in Settings).

3. Adaptive Portrait Display

In portrait orientation, the app can automatically switch to single-page display (enabled by default, configurable in Settings) for optimal readability.

4. How to toggle toolbars and controls?

Tap once on the center of the screen to show or hide the top and bottom toolbars.

5. How to zoom and pan?

Pinch with two fingers to zoom in or out. When zoomed in, long-press and drag to scroll around the document.

6. How to search inside a PDF?

Type your search query into the search bar at the top to instantly find matching text with highlighted bounding boxes (yellow background and red border).

7. Testing & Diagnostics & App Logs

Access "Testing & Diagnostics" in Settings to run device diagnostic tests, inspect real-time memory usage, and view or share local application logs. Logs are securely stored locally for up to 24 hours, contain zero personal/file data, and are never sent externally automatically.

8. Supporting the Developer

All core features (including two-page spreads and search) are 100% free with no ads. If you enjoy the app, you can support further development via the in-app "Support" screen (Bronze, Silver, and Gold tip tiers as non-consumable purchases), which displays special commemorative badges in your settings screen.

9. Reporting Bugs & Issues (GitHub Issues)

If you encounter any issues, crashes, or unexpected behavior, please report them via GitHub Issues. When creating an issue, please include:

  • App Version (e.g., v2.0.0, Code 23)
  • Device & OS (e.g., Pixel 8, Android 15)
  • Steps to Reproduce the problem
  • Diagnostic Logs: You can copy or share app logs from Settings > Testing & Diagnostics to help diagnose issues quickly. (Logs never contain personal data or document contents).
