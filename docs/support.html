Frequently Asked Questions (FAQ) & Guide

1. How to open a PDF?

Tap the folder icon or open button in the toolbar to select a PDF file from your device storage or cloud storage using the system file picker.

2. How to navigate pages?

Swipe left/right across the screen, or use the bottom page slider.

3. How to toggle toolbars and controls?

Tap once on the center of the screen to show or hide the top and bottom toolbars.

4. How to zoom and pan?

Pinch with two fingers to zoom in or out. When zoomed in, long-press and drag to scroll around the document.

5. How to search inside a PDF?

Type your search query into the search bar at the top to instantly find matching text with highlighted bounding boxes.

6. Supporting the Developer

All core features (including two-page spreads and search) are 100% free with no ads. If you enjoy the app, you can support further development via the in-app "Support" screen (Bronze, Silver, and Gold tip tiers).

7. Contact & Support

If you encounter any issues or have feature requests, please visit our GitHub Repository.
