Patakaran sa Privacy

Ang developer ng MihirakiPDF ("ang App") ay iginagalang ang iyong privacy. Binabalangkas ng patakarang ito kung paano namin pinangangasiwaan ang impormasyon.

1. Koleksyon at Paggamit ng Impormasyon

Ang App ay **hindi** nag-a-upload o nangongolekta ng iyong mga PDF file. Ang lahat ng pagproseso ng PDF ay lokal na ginagawa sa iyong device. Ginagamit lang ng App ang koneksyon sa internet sa mga sumusunod na limitadong sitwasyon:

  • Kapag tahasang nagbukas ka ng file mula sa mga cloud storage service tulad ng Google Drive.
  • Kapag nagsagawa ka ng in-app purchase (support tips) sa pamamagitan ng Google Play Billing system.

2. Mga Pahintulot

Ginagamit ng App ang Storage Access Framework (SAF) para ma-access lang ang mga partikular na file na pipiliin mo. Hindi kami humihingi ng malawak na pahintulot sa pag-access sa storage.

3. Seguridad ng Data

Dahil hindi kailanman umaalis sa iyong device ang iyong mga dokumento, mananatili sa ilalim ng iyong kontrol ang iyong data.

4. Makipag-ugnayan

Para sa mga katanungan tungkol sa patakarang ito, mangyaring makipag-ugnayan sa pamamagitan ng GitHub repository.
