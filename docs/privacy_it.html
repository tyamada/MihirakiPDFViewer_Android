Informativa sulla privacy

Lo sviluppatore di MihirakiPDFViewer ("l'App") rispetta la tua privacy. Questa informativa descrive come vengono gestite le informazioni.

1. Raccolta e utilizzo dei dati

L'App non carica né raccoglie i tuoi file PDF. Tutta l'elaborazione dei PDF avviene localmente sul tuo dispositivo. L'App utilizza la connessione Internet solo nei seguenti casi limitati:

  • Quando apri esplicitamente un file da servizi di archiviazione cloud come Google Drive.
  • Quando effettui un acquisto in-app facoltativo (mancia di supporto) tramite Google Play Billing.
  • I PDF vengono elaborati localmente sul dispositivo. Le connessioni di rete sono utilizzate per il download dei PDF di esempio, i servizi cloud, il controllo aggiornamenti e gli acquisti di supporto facoltativi.

2. Autorizzazioni

L'App utilizza lo Storage Access Framework (SAF) per accedere solo ai file selezionati esplicitamente dall'utente. Non richiediamo autorizzazioni di accesso esteso all'archiviazione.

3. Sicurezza dei dati

Poiché i documenti non lasciano mai il tuo dispositivo, i tuoi dati restano sempre sotto il tuo controllo.

4. Contatti

Per domande su questa informativa, contattaci tramite il repository GitHub.
