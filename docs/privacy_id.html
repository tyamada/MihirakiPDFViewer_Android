Kebijakan Privasi

Pengembang MihirakiPDF ("Aplikasi") menghormati privasi Anda. Kebijakan ini menguraikan bagaimana kami menangani informasi.

1. Pengumpulan dan Penggunaan Informasi

Aplikasi **tidak** mengunggah atau mengumpulkan file PDF Anda. Semua pemrosesan PDF dilakukan secara lokal di perangkat Anda. Aplikasi hanya menggunakan konektivitas internet dalam skenario terbatas berikut:

  • Saat Anda secara eksplisit membuka file dari layanan penyimpanan cloud seperti Google Drive.
  • Saat Anda melakukan pembelian dalam aplikasi (tips dukungan) melalui sistem Google Play Billing.

2. Izin

Aplikasi menggunakan Storage Access Framework (SAF) untuk mengakses hanya file tertentu yang Anda pilih. Kami tidak meminta izin akses penyimpanan yang luas.

3. Keamanan Data

Karena dokumen Anda tidak pernah keluar dari perangkat Anda, data Anda tetap berada di bawah kendali Anda.

4. Kontak

Untuk pertanyaan mengenai kebijakan ini, silakan hubungi melalui repositori GitHub.
