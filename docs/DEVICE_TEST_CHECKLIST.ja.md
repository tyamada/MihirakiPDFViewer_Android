# 内部テスト版2.1.4（43）実機確認手順

> **修正版の確認**：現在の内部テストは2.1.4（44）。利用者より応援画面のスクロール・TalkBack・購入済み表示の再確認合格を受領済みです。以下は確認手順として保持します。詳細はINTERNAL_TEST_DISTRIBUTION_2.1.4_44.ja.md。

更新前に保存したスクリーンショットを比較に使います。アプリの削除・データ消去・Debug版のインストールは行わず、Google Playから更新した状態で確認してください。実機スクリプトは改善済みです。既定の情報収集モードは利用できますが、今回のPlay更新確認ではDebug試験・クリーンインストールは行いません。操作手順はDEV_TESTING_GUIDE.mdを参照してください。

## 準備

端末名、Androidバージョン、確認日時を記録。アプリの「バージョン」で2.1.4（43）を確認し、画面を保存します。元からあるローカルPDF、文字検索できるPDF、目次付きPDF、必要ならパスワード付きPDFを用意します。個人情報のあるPDFやパスワードは報告に添付しないでください。

## 購入を新しく試す場合

内部テスターと課金のライセンステスターは別設定です。新規購入試験は、ライセンステスター設定と購入画面にテスト決済である表示があることを確認してから行います。通常の決済が表示されたら購入を確定せず戻ってください。既購入権利の保持確認だけなら新規購入は不要です。

## 記録と判定

各番号を「合格／不具合／未実施／対象外」で記録してください。全体を一括して「問題なし」とせず、端末・OS・アプリ版・操作・期待値・実際の結果を残します。更新後の同じ画面を撮影し、更新前と比較します。不具合は再現手順と画面を保存。診断ログを共有する場合も、内容を確認して個人情報を除いてください。

記録例：端末___／Android___／2.1.4（43）／日時___／項目4 合格／日本語で3→2→1、切替後1→2→3、再起動後維持／画像___。

起動不能、設定・購入権利消失、普段のPDFが開かない、主要操作不能があれば製品版へ進めず調査します。TalkBackと更新前後の保持は自動テストだけで合格にせず、この実機確認結果を報告書へ反映します。
