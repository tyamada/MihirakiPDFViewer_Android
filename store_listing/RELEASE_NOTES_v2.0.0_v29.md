# Release Notes v2.0.0 (Version Code 29)

## 日本語 (Japanese)
- **Ver.2.0公開記念こよみバッジの追加**: Ver.2.0の公開を記念したスペシャルサポーターバッジ「Ver.2.0公開記念こよみバッジ」を追加しました。Google Play Consoleのプロモーションコード機能（コードの利用）に対応し、世界中のすべてのユーザーが無料で安全に獲得・表示できるようになりました。
- **購入・プロモコードの自動同期強化**: Playストアアプリでプロモーションコードを利用した際や、バックグラウンドでの購入状態をアプリ起動時（応援画面・設定画面表示時）に即座に自動同期・反映するよう改善しました。
- **UI・多言語対応およびアクセシビリティの改善**: サンプルPDF画面などのテキスト多言語化や、アクセシビリティ（コンテンツ説明）を強化しました。

## English
- **Ver.2.0 Release Commemoration Koyomi Badge**: Added a special commemorative supporter badge—the "Ver.2.0 Release Commemoration Koyomi Badge"—with full support for Google Play Console promotional codes, enabling seamless free redemption for users across all regions.
- **Instant Purchase & Promo Code Synchronization**: Enhanced background purchase querying so that promo codes redeemed directly in the Play Store app or out-of-app purchases are instantly synchronized and displayed upon opening the Support or Settings screens.
- **Localization & Accessibility Improvements**: Localized sample PDF screen texts and improved overall accessibility (content descriptions).
