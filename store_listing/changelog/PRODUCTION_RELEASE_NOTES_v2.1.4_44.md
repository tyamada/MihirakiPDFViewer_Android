# 製品版用リリースノート案：2.1.4（44）

製品版2.1.3（42）からの累積変更。内部テスト44の修正差分ノートとは別に、製品版へ進める際の転記用に準備したものです。Consoleへの登録・審査送信は未実施。配信国・価格は変更しません。

## en-US

<en-US>
Added saved sorting for sample PDFs. Improved translations, help and app icons. Fixed settings persistence, compact search controls and navigation when opening PDFs from other apps. Improved screen reader labels and fixed the Support screen so all content can be reached when using larger text.
</en-US>
