## 日本語

Android向け「見開きPDFビューア」2.1.4の更新内容です。

- サンプルPDFの第1話順・最新話順の切替と、選択した順序の保存。
- 各言語の翻訳、ヘルプ、アプリアイコンの改善。
- 設定保存の競合、狭い画面の検索欄、他アプリからPDFを開いた際の画面遷移の修正。
- ページ操作の読み上げ説明と、文字拡大時の応援画面のスクロール・配置の改善。

閲覧機能は購入なしで利用できます。応援購入はGoogle Playの非消耗型商品です。価格や配信国の変更はこのリリースに含めません。

## English

Updates to Mihiraki: Two-Page PDF Reader for Android:

- Sort sample PDFs from Episode 1 or the latest episode, with the selected order saved.
- Improved translations, help and app icons.
- Fixed settings persistence, compact search controls and navigation when opening PDFs from other apps.
- Improved screen reader labels and scrolling on the Support screen when using larger text.

Reading features remain available without purchase. Optional support purchases are non-consumable Google Play products. This release does not change prices or distribution countries.
