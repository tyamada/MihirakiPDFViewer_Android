# Release Notes - v2.1.3 (Code 41)

## English
- Renamed "App Info" menu item and screen title to "Version" for cross-app consistency.
- Localized update check result messages (toast notifications, cooldowns, and error handling) for seamless multilingual support.
- Enabled R8 full mode, optimized ProGuard/R8 rules, and refactored codebase for enhanced performance and cleanliness.
- Enhanced accessibility compliance and test verification.

## 日本語
- 他のアプリとの不整合を解消するため、メニューおよびアプリ情報画面の名称を「バージョン」に変更。
- 「更新を確認」実行後の結果表示（トースト通知、クールダウン、エラーメッセージ）をローカライズし、端末の言語設定に最適化。
- R8フルモードの有効化とProGuard/R8ルールの最適化、コードベースのリファクタリングによりパフォーマンスと保守性を向上。
- アクセシビリティ対応の強化およびテスト検証を実施。
