# 自動撮影機能の実装・検証結果

対象: v2.0.0 / versionCode 31。2026-10-15。

## 実装

- scripts/store_capture_config.jsonに端末別scene・向き・解像度・密度・言語・対象版・掲載順を集約。スマホ／タブレット7画面、Desktop6画面、4言語で108枚を選択可能。
- 撮影スクリプトへDesktop、目次、7インチの一時解像度変更と復元、未対応組合せの開始前拒否、同時実行ロック、未完了一覧を追加。
- PDFを一時領域へADB pushし、ハッシュ検証後にrun-asでアプリ専用領域へコピー。Downloadsへの書込みは不要。
- 最新の設定メニューへ撮影テストを対応。目次では8項目のページ番号と3ページ目への移動を検証。
- Desktopの初期ウィンドウを最大化／タスクサイズ変更し、実際のActivity領域を検査。矢印キーとComposeのマウス入力でページ移動を検証。ウィンドウリサイズ枠を避け、幅10%の位置をクリックする。
- 表示設定は最下部のオプション群までスクロールして撮影し、読書設定との重複を防止。
- 画像を不透明RGB PNGへ保存し、版・言語・寸法・向き・描画・検索ハイライト・目次・最大化・重複を検査。旧版画像の互換再利用は廃止。
- 検品処理を可変scene数・掲載順・部分選択・可変行高の一覧生成へ対応。全選択範囲の検査後だけ目視完了を記録。

## 撮影試験で修正した既存不具合

- PDF目次がGoToアクションを持つ場合に移動先を解決できず、全項目をp.1としていた。PDFBoxのfindDestinationPageで直接・名前付き・GoToの移動先を解決するよう修正。
- 読書方向とマウス設定の変更がpointerInput(Unit)に反映されないため、両値をpointerInputのキーへ追加。
- ビルドを妨げていたhelp_sliderとreport_issue_descのデフォルト文字列不足を補完。
- 目次見出しとボタン説明を文字列リソース化し、対象4言語を追加。
