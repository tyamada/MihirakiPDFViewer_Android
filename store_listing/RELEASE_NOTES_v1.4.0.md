# Release Notes v1.4.0 (Version Code 22)

## 🇯🇵 日本語 (Japanese)
- **非消耗型チップ対応**: iOS版アプリストアの審査ガイドラインに準拠するため、サポーター応援チップの購入処理を非消耗型（Non-consumable）に変更しました。これにより一度購入したサポートバッジが永続的に保持・復元されます。
- **ストア情報の整理**: Google Playストア向けの掲載画像（アプリアイコン、機能グラフィック、チップアイコン等）およびサンプルPDFを最新の状態に整理・更新しました。

## 🇬🇧 English
- **Non-Consumable Tips**: Updated tip purchases from consumable to non-consumable to comply with App Store review guidelines, ensuring supporter badges are permanently retained and restored.
- **Store Listing Organization**: Reorganized and updated store listing assets (app icons, feature graphics, tip icons) and sample PDFs.
