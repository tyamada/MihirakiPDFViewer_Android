# Release Notes v1.3.0 (Version Code 21)

## 🇯🇵 日本語 (Japanese)
- **設定画面のレイアウト改善**: 設定画面のオプション（表紙設定・リセット）グループを、ドキュメント情報の下、ヘルプの上の位置に移動し、より直感的な操作ができるようにしました。
- **パフォーマンスと安定性の向上**: R8の最適化およびネイティブシンボルの組み込みにより、クラッシュレポートの精度向上とパフォーマンス最適化を図りました。

## 🇬🇧 English
- **Settings Layout Improvement**: Relocated the options group (cover settings and reset) below document information and right above help for a more intuitive settings experience.
- **Performance & Stability**: Enabled advanced R8 optimizations and native debug symbols for improved crash reporting and runtime performance.
