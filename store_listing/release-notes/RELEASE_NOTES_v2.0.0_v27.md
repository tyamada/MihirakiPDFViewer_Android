# Release Notes v2.0.0 (Version Code 27)

## 日本語 (Japanese)
- **Ver.2.0公開記念こよみバッジの追加**: Ver.2.0の公開を記念した無料の「Ver.2.0公開記念こよみバッジ」を追加しました。応援・チップ画面から無料で取得でき、設定画面にサポーターバッジとして表示されます。
- **UIおよび安定性の改善**: 各種レイアウトの最適化および動作の安定性向上を行いました。

## English
- **Ver.2.0 Release Commemoration Koyomi Badge**: Added a free "Ver.2.0 Release Commemoration Koyomi Badge" to celebrate the v2.0 release. Supporters can claim it for free from the Support screen, and it will be displayed as a badge on the Settings screen.
- **UI and Stability Improvements**: Various layout optimizations and stability enhancements.
