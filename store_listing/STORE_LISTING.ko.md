# Google Play 스토어 등록정보 (한국어)

Google Play Console의 "스토어 등록정보" 입력용 초안입니다.

## 앱 이름 (최대 30자)
MihirakiPDFViewer - 양면 펼쳐보기

## 간단한 설명 (최대 80자)
만화에 최적! 펼쳐보기와 우측 읽기(R2L)를 지원하는 프라이버시 중심 PDF 뷰어.

## 자세한 설명 (최대 4000자)
**MihirakiPDFViewer**는 일본 특유의 "우측 읽기(R2L)" 및 "펼쳐보기(두 페이지)" 문서를 안드로이드 기기에서 가장 편안하게 감상할 수 있도록 설계된 PDF 뷰어입니다. 만화, 화집, 라이트노벨, 기술 서적 등 모든 PDF를 원래의 레이아웃으로 즐기실 수 있습니다.

### ✨ 주요 기능
- 📖 **몰입감 있는 펼쳐보기**: 두 페이지를 나란히 표시하여 만화나 화집의 감동을 그대로 전달합니다.
- 🔄 **스마트 자동 감지**: PDF 메타데이터를 분석하여 최적의 읽기 방향(우측 읽기/좌측 읽기)과 레이아웃을 자동으로 설정합니다.
- 🇯🇵 **우측 읽기(R2L) 완벽 지원**: 일본 도서에 최적화된 우에서 좌로의 페이지 넘김을 네이티브 지원하며, 슬라이더 방향도 직관적으로 전환됩니다.
- 🔍 **정밀 검색 및 하이라이트**: 빠른 텍스트 검색과 함께 검색 결과 위치를 배경색과 테두리(노란 배경 및 빨간 테두리)로 명확하게 표시합니다.
- 🖱️ **마우스 및 가장자리 클릭 페이지 이동**: 데스크톱/마우스 조작 모드에서 PDF 이미지의 좌우 가장자리를 클릭하여 직관적으로 페이지를 넘길 수 있습니다 (설정에서 변경 가능).
- 📱 **적응형 세로 모드 표시**: 세로 화면(Portrait)일 때 자동으로 한 페이지 표기로 전환되는 기능을 탑재했습니다 (스마트폰은 기본적으로 한 페이지, 설정에서 변경 가능).
- 🎨 **적응형 디자인**: 스마트폰, 태블릿, 폴더블 기기의 모든 화면 크기와 방향(세로/가로)에 최적화되어 있습니다.
- 📋 **진단 및 로그 관리**: 인앱 기기 진단 테스트 실행 및 로컬 앱 로그 관리 기능을 제공합니다. 로그는 기기 내에 최대 24시간 동안 안전하게 보관되며, 개인정보나 파일 내용은 일체 기록되지 않고 외부로 자동 전송되지 않습니다.

### 🛡️ 프라이버시와 보안
- **완전 로컬 처리**: PDF 파일을 외부 서버에 업로드하지 않습니다. 모든 렌더링과 검색은 기기 내에서 수행됩니다.
- **최소한의 권한**: 불필요한 전체 저장소 권한을 요구하지 않습니다. Storage Access Framework(SAF)를 채택하여 사용자가 명시적으로 선택한 파일에만 안전하게 접근합니다.
- **오프라인 지원**: 로컬 파일을 읽을 때 인터넷 연결이 필요 없습니다.

### 💖 개발자 후원
이 앱은 광고가 없으며 완전 무료로 제공됩니다. PDF 보기, 펼쳐보기, 검색을 포함한 모든 핵심 기능은 구매 여부와 관계없이 제한 없이 무료로 이용하실 수 있습니다. 앱이 마음에 드신다면 인앱 "후원" 화면을 통해 개발을 지원해 주실 수 있으며(브론즈, 실버, 골드 소모되지 않는 후원 팁), 설정 화면에 특별한 기념 배지가 표시됩니다.

*참고: 텍스트 레이어가 없는 스캔 이미지 전용 PDF에서는 검색 기능을 사용할 수 없습니다.*
