## Full description (Max 4000 chars)
**MihirakiPDFViewer** é um leitor de PDF moderno e focado na privacidade, projetado para a leitura confortável de documentos da direita para a esquerda (R2L) e visão dupla.

### ✨ Key Features
- 📖 **Visão Dupla**: Aproveite duas páginas lado a lado em telas grandes.
- 🔄 **Suporte R2L Completo**: Suporte nativo para a ordem de leitura da direita para a esquerda.
- 📱 **Suporte para Chromebook**: Otimizado para tablets e telas grandes de Chromebook.
- 🛡️ **Privacidade em Primeiro Lugar**: Processamento local de PDF sem conexões desnecessárias.
