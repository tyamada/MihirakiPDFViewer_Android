Ouvrir le PDF : Utilisez le sélecteur de fichiers pour sélectionner un PDF.

PDF d'exemple : Téléchargez et essayez les PDF d'exemple fournis.

Menu : Touchez l'écran pour afficher ou masquer la barre d'outils.

Navigation : Glissez, utilisez le curseur ou cliquez sur les bords pour changer de page.

Table des matières (Outline) : Appuyez sur l'icône de la table des matières pour accéder instantanément aux chapitres.

Mise en page adaptative : Optimisé automatiquement pour les tablettes et pliables.

Zoom : Pincez pour zoomer. Maintenez et faites glisser pour faire défiler.

Recherche : Entrez du texte pour rechercher dans le PDF.

Paramètres : Personnalisez les options d'affichage et consultez les informations.
