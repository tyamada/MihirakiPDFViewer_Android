Buka PDF: Gunakan pemilih file untuk memilih file PDF.

PDF Sampel: Unduh dan coba file PDF sampel.

Menu: Ketuk layar untuk mengalihkan visibilitas bilah alat.

Navigasi Halaman: Geser, gunakan penggeser, atau klik tepi kiri/kanan.

Daftar Isi (Outline): Ketuk ikon daftar isi untuk langsung melompat ke bagian mana pun.

Tata Letak Adaptif: Dioptimalkan secara otomatis untuk tablet dan perangkat lipat.

Zoom: Cubit untuk memperbesar atau memperkecil.

Pencarian: Masukkan teks untuk mencari konten dalam PDF.

Pengaturan: Sesuaikan pengaturan tampilan.
