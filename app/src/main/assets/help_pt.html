Abrir PDF: Use o seletor para selecionar um arquivo PDF.

PDFs de Exemplo: Baixe e teste arquivos PDF de exemplo.

Menu: Toque na tela para alternar a barra de ferramentas.

Navegar: Deslize, use o controle deslizante ou clique nas bordas.

Sumário (Outline): Toque no ícone de sumário para ir para qualquer seção.

Layout Adaptativo: Otimizado automaticamente para tablets e dobráveis.

Zoom: Conecte os dedos para zoom. Pressione e arraste para rolar.

Pesquisa: Digite texto para pesquisar no PDF.

Configurações: Personalize as opções de exibição.
