Abrir PDF: Use el selector de archivos para seleccionar un PDF.

PDFs de muestra: Descargue y pruebe los archivos PDF de muestra.

Menú: Toque la pantalla para alternar la visibilidad de la barra de herramientas.

Navegar páginas: Deslice, use el control deslizante o haga clic en los bordes.

Índice (Outline): Toque el icono de índice para saltar a cualquier sección.

Diseño adaptable: Optimizado automáticamente para tabletas y plegables.

Zoom: Pellizque para hacer zoom. Mantenga presionado y arrastre para desplazar.

Buscar: Ingrese texto para buscar contenido específico en el PDF.

Ajustes: Personalice la configuración de visualización.
